## ✨ What SQ8L Actually Does For You

The original Ensoniq SQ-80 was a hybrid synthesizer that blended digital wave sounds with an analog-style filter. It became famous for lush pads, biting basses, glassy bells, and choir-like textures that showed up on countless records in the late 80s and early 90s. Real units are now decades old, increasingly expensive, and increasingly difficult to keep running.

SQ8L recreates that instrument in software. It behaves like a plug-in, which means it opens inside the music program you already use — the same place you record, arrange, and mix. You get the character of the original machine without needing the original machine.

Because this release is a 64-bit port, it works with current versions of Windows and current music software. The older 32-bit builds of the classic SQ8L simply cannot load into most modern setups; this port exists specifically to solve that problem.

## 🎚️ Which Format Do You Need?

Seeing four unfamiliar abbreviations can be confusing. Here is the plain version:

- **VST3** — the most common format on Windows. If you are unsure, start here.
- **VST2** — an older standard, still used by some programs for compatibility.
- **AU** — the format used by macOS music software.
- **CLAP** — a newer, modern standard that a growing number of programs support.

You only need the one your music software recognizes. Installing all of them is harmless, and having extras around saves time later if you switch programs.

## 🩺 If Something Does Not Work

**SQ8L does not appear in my instrument list.** Your music software is probably looking in a different folder than the one the plug-in went into. Check the plug-in folder settings in your program's preferences and point it at the correct location.

**The sound is silent.** Confirm the track is armed or that notes are actually being sent. Also check that the plug-in is loaded on an instrument track rather than an audio track.

**My computer feels slow with it running.** Close other demanding programs while you work. A single instance of SQ8L is light, but stacking many at once on an older machine will add up.

**I downloaded it but nothing opens.** This is expected — as mentioned above, SQ8L runs inside your music software, so there is nothing to double-click on its own.

## 🛡️ Why Preservation Matters

Vintage digital instruments are fragile in a specific way: when the hardware fails, the sound disappears with it, because much of the behavior lived inside chips that were never documented publicly. Projects like this one exist to make sure that does not happen. Rebuilding the instrument in software — and reverse engineering the details carefully enough to be faithful — keeps this part of music history playable long after the original machines stop working. This 64-bit port is a continuation of that effort, and it is released so that the sound stays available to everyone.
